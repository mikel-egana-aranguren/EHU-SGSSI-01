Criptosistemas simétricos modernos

Cifran bits en vez de texto

Cifrado en flujo (Stream ciphers): cifrar un flujo continuo de bits

Cifrado en bloque (Block ciphers): dividir el mensaje en bloques del mismo tamaño y aplicar el algoritmo a cada uno

Stream ciphers

Cifran un flujo bit a bit

Usado para comunicaciones en tiempo real (No se puede esperar a tener el mensaje completo para cifrarlo y transmitirlo)

Stream ciphers

A partir de la clave, se usa un generador pseudoaleatorio que genera el flujo de clave (de manera determinista, pero parece aleatoria) de igual tamaño que el mensaje

La operación XOR entre el bit a cifrar y el flujo de clave genera el criptograma

Stream ciphers

Stream ciphers: XOR

Reversible

No pierde información

Muy eficiente

Clave aleatoria, salida parece aleatoria

One time pad irrompible: C = P XOR K (K totalmente aleatoria, tan largo como mensaje, usada una sola vez)

Stream ciphers

No reutilizar la misma clave para cifrar múltiples mensajes

Keystream = F(clave, nonce)

  • Clave: secreta y fija
  • Nonce: público y diferente para cada mensaje

Block ciphers

Partir el mensaje original en bloques de tamaño fijo

Cada bloque de mensaje original genera un bloque de mensaje cifrado

Se pueden añadir iteraciones, permutaciones y operaciones entre los distintos bloques

DES (Data Encryption Standard)

  • 1975, Primer estándar
  • Bloques de 64 bits
  • Clave de 56 bits (64 - 8 como propuesta de la NSA para asegurarse de que podian romperlo -???-)
  • Se considera inseguro actualmente: ej. ataque fuerza bruta: Wiener, M. J. (1999). "Efficient DES Key Search". Practical Cryptography for Data Internetworks. Indiana University: Research Institute for Advanced Computer Science. ISBN 0-8186-8828-1.

Triple DES

  • Concebido como sucesor de DES, todavia en uso pero no recomendado desde 2023 (CVE-2016-2183)
  • Basado en realizar 3 ejecuciones de DES (Cifrar - Descifrar - Cifrar)
  • Bloques de 64 bits
  • Claves de 168 bits (3*56), clave efectiva 112 bits

AES (Advanced Encryption Standard)

  • Rijndael
  • Estandarizado por el Instituto Nacional de Normas y Tecnología (NIST), EEUU
  • Sustituto de (Triple) DES
  • Muy usado en todo tipo de comunicaciones y transacciones
  • Bloques de 128 bits
  • Claves de 128, 192 o 256 bits

IDEA (International Data Encryption Algorithm)

  • Bloques de 64 bits
  • Clave 128 bits
  • 8 rondas y media
  • Está considerado seguro (excepto algunas claves débiles)
  • Incluído en OpenPGP
